## Cómo usar esta documentación

1. Consultar el plan maestro antes de iniciar una tarea.
2. Trabajar dentro del área correspondiente.
3. Mantener las tareas pequeñas y verificables.
4. Actualizar la documentación cuando cambien decisiones o contratos.
5. No marcar una tarea como terminada sin criterios de aceptación comprobados.

El plan maestro describe el primer demo jugable. El [roadmap de evolución futura](./plan/LONG-TERM-ROADMAP.md) registra las etapas posteriores, como personajes, inventario, combate, backend y multiplayer, sin convertirlas todavía en trabajo activo.
